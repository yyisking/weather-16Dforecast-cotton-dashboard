# 棉花供需与天气胁迫公开看板 V0.7

本目录是独立的公开展示站点，不覆盖 `cotton/dashboard/` 旧看板。

## 展示边界

- 供需数据来自 USDA FAS 2026 年 9 月六行 V0.2 决策简报（World、中国、美国、巴西、印度、澳大利亚）。
- 天气评分区来自美国得州、中国新疆、印度中部雨养带、巴西马托格罗索和澳大利亚东部棉区的当地理论天气胁迫指数；每区同时展示独立的 14 日原始天气层（°C、mm、MJ/m²/日）和 0—100 模型因子层。
- 中亚五国十个 AOI 为独立的定性天气观察区，显示中文名和天气异常度；不参与评分区卡片、跨区排名或供需换算。异常度只表示同一 AOI 的当地同期偏离，异常度高不表示天气对棉花更不利；棉花胁迫分保持 0/10 可用。
- 0—100 分不是减产百分比、概率、价格预测或交易建议。
- 五个评分区合同不同，不直接加总、排名或生成伪全球天气分；中亚综合胁迫分保持未计算。
- 澳大利亚评分区详情展示 USDA 官方产量和期末库存变化；天气指数不换算为产量或供给数量。澳大利亚与 ABARES 侧车的单位不混合。
- 公开供需表固定为全球加五个国家共六行；中亚观察 AOI 不在供需表内。
- 空值保留为“暂无可用值”或“当前阶段未纳入”，不得填成 0。原始天气是点位网络聚合，不是单站实测；缺点位或不足 60% 覆盖时保留 null。
- seasonal 图按各地合同窗口裁剪；新疆春季风害图仅显示评分启用期 04-01—05-31，6—11 月不进入该图轴，但底层审计序列仍保留；澳洲按 2026/27、2025/26 跨年作季排列 9 月至次年 6 月，中亚 3—10 月是未核实当地阶段的页面代理窗口。
- 新疆、得州、巴西 MT 与澳洲均使用 append-only 连续温度后继版：各自在当地模型窗口内同时保留低温与高温方向，原主权重不变，原硬排除方向以 `0.5` 暂定次要权重纳入。印度仍只有热旱复合因子，本轮未补造独立低温模型。所有权重仍未校准。

## 构建

运行 `python3 build_public_dashboard.py`，同步生成根目录和 `dist/` 的 `data.json`，并确保两份 `index.html` 字节一致；页面文件为 `dist/index.html`。
V0.7 页面当前使用 payload cache key `v=20260929-v11-latest-date-refresh`。顶部以“全球棉花五大种植区域天气胁迫总评分（产区产量加权）”标注展示合成分；共同截止仍受澳洲 2026-09-10 数据上限约束，点击总分可打开共同截止口径的季节图。地区卡和原始天气层分别采用各自产区真实可用的最新完整日期：新疆、得州、印度为 2026-09-29，巴西为 2026-09-28，澳洲为 2026-09-10。产量权重表收在默认关闭、键盘可操作的原生 details 中，summary 为“产量加权详情”。地区详情明确说明温度/辐射为截至当日过去 14 天日值平均，降水为过去 14 天累计，并且均先按点位计算再做棉区点位网络聚合。

展示合成仅按当前五区产量加权当地理论分，不是统一全球模型或减产百分比；共同截止日、产量/权重、coverage 与季节图均可追溯。合成图固定 0—100 轴，覆盖不足不按 0 处理，历史带不补造澳洲历史分。评分图固定 0—100 轴；raw 图按真实单位自动缩放，降水/短波辐射自动轴不显示负下界。新疆、得州、巴西 MT、澳洲的高低温在各自当地模型窗内连续；其他阶段门控因子仍用灰色表示未启用，未来值与源数据缺口分别标注。原始降水与降水相关模型分数不混用。
