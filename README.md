# 棉花供需与天气胁迫公开看板 V0.1

本目录是独立的公开展示站点，不覆盖 `cotton/dashboard/` 旧看板。

## 展示边界

- 供需数据来自已验收的 USDA FAS 2026 年 9 月快照。
- 天气数据来自美国得州、中国新疆、印度中部雨养带和巴西马托格罗索的当地理论天气胁迫指数。
- 0—100 分不是减产百分比、概率、价格预测或交易建议。
- 四区合同不同，不直接加总、排名或生成伪全球天气分。
- 空值保留为“暂无可用值”或“当前阶段未纳入”，不得填成 0。

## 构建

运行 `python3 build_public_dashboard.py`，生成 `dist/data.json`；页面文件为 `dist/index.html`。
